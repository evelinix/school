# Tests

## Lapisan E2E memakai Playwright
Kerangka E2E resmi = Playwright (@playwright/test). Belum terpasang — jangan tulis *.spec.ts sebelum bun add -D @playwright/test dan konfigurasi disetujui. Test utama tetap Pest (unit+feature). jangan digabung ke bun run check.
